# MUSE Multi-Agent Orchestration

> 已安装状态：v0.1.0（2026-11-11 激活，R4-F Grok 修复已应用；
> R6-E1 图片接线已部署，真实图片功能默认关闭）。
> 本文件为受限编排入口的 Skill，只处理 A 类非敏感任务，
> 生产 cron 与生产 Skill 不受影响。

## 适用场景

当用户用自然语言提出以下任务时读取本 Skill 全文并按方法执行。

- 日语文案改写、中文创作、独立内容评审
- X 趋势研究、话题发现、研究资料整理
- 图像生成需求（中英文：生成图片/配图/插图/画一张/做一张图/生成一张图片/帮我画一张图/创建一张插画/生成 PNG 图片/画一只猫；generate an image / create a picture / draw a picture / generate a PNG / make an illustration；默认走模拟路径，真实生成由功能开关控制，默认关闭）
- 简单任务（MUSE 直接完成，不委派）
- 敏感任务（门禁拦截，不委派）

## 委派前先判断

- 先用分类规则判断任务能力。日语改写走 agy。中文创作与内容评审走 agy。X 趋势与话题发现走 Grok。图像生成需求走 Codex（默认模拟路径）。事实核查与简单计算由 MUSE 直接完成。
- 路由优先级：1）敏感信息与安全门禁（权威，分类之后仍拦截）；2）明确的图片生成任务；3）日语任务 → agy；4）Grok 公开研究任务；5）其他既有路由；6）简单任务由 MUSE 直接处理。
- 图片编辑、图片分析、图片搜索与仅提到图片（如“这张图片很好看”“请分析这张图片”）不是图片生成，不要路由到 Codex 图片生成。
- 日语文案改写不论长短都优先走 agy，哪怕只有一句话，也不要直接写。篇幅长短不是判断标准，任务类型才是。
- 简单中文改写、算术、事实核查与简短问候由 MUSE 直接完成，不要委派。
- 任务不匹配任何能力时由 MUSE 直接完成，不要强行委派。
- 任务含真实客户资料、生产写操作、对外发送或发布、真实图像生成时不要委派，直接按安全门禁拒绝并说明原因。
- 不要让所有任务强制经过外部 Agent。

## 执行方法

- 在终端用统一入口提交任务，命令为 `cd ~/workspace/muse-orchestration-r3 && python3 muse_orchestrate.py run "<自然语言任务>"`。
- 等待入口返回结果摘要，其中包含任务编号、执行器、最终状态与收据引用。
- 把结果摘要与执行器输出一起返回当前对话，不要只给任务编号。
- 用 `python3 muse_orchestrate.py receipts <任务编号>` 查询收据，用 `python3 muse_orchestrate.py tasks` 列出任务状态。
- 图片任务返回的是草稿（默认模拟草稿；真实生成须功能开关显式启用，隔离验收外默认关闭），状态为已展示、不可用。用户用 `python3 muse_orchestrate.py approve-image <任务编号> --confirm` 明确批准后才可用。没有 `--confirm` 时拒绝批准。
- 真实图片功能开关 `codex.real_image_generation_enabled` 默认关闭，缺失或无效配置时关闭；不得通过用户自然语言请求或任务参数打开。

## 失败与回退

- 入口返回委派失败时先读收据中的错误类别，再按类别处理。额度耗尽不重试。未知状态不盲目重试。
- 熔断触发时入口返回回退给 MUSE，由 MUSE 直接完成或请用户决定，不要自动恢复调度。
- 重复提交返回首次结果，不重复执行。
- 门禁拦截返回 SECURITY_BLOCKED 时不要换说法重试，不要绕过门禁。

## 停用与回滚

- 停用入口时在终端运行 `cd ~/workspace/muse-orchestration-r3 && python3 muse_orchestrate.py rollback --reason "<原因>"`，之后所有委派被拒绝，直接调用不受影响。
- 原因修复后由人工运行 `python3 muse_orchestrate.py enable` 恢复。
- 彻底移除本 Skill 时删除 `~/workspace/custom-skills/muse-orchestration/` 目录，入口即不可发现，框架本身不受影响。

## 安全边界

- 隔离是 CLI 权限引擎层，不是内核层。不要把文本门禁说成操作系统级读取隔离。
- Codex 沙箱不限制读取。不要向 Codex 任务传递敏感路径。
- 收据与任务库权限为 0600，不要把收据原文发给无关方。
- 真实客户资料永不进入外部 CLI。虚构数据只用于测试。
